## Who can request access?

* **Researchers and students** are granted access upon filling out our access request form. 


## How to request access
* Fill out the [access request form](https://serviceportal.aau.dk/serviceportal?id=sc_cat_item&sys_id=37b26fd4c3afee10f0f3041ad00131d0){target="_blank}. 
* The request is processed manually, so please expect a bit of delay before you can start using AAU Compute.
