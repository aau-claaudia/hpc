# Mistral is now approved for processing sensitive data

We are pleased to announce that from **1 September 2026**, Mistral is approved for **Level 3 data** at Aalborg University.

AAU researchers can now use [Vibe](/mistral/guides/vibe/) and [AI Studio](/mistral/guides/ai-studio/) with data classified as Level 1, 2, **and 3** under [AAU’s data classification](https://www.security.aau.dk/data-classification){target="_blank"}. That is a significant step: generative AI for academic research is no longer limited to the least sensitive material.

This opens the door to a wider range of research tasks in the browser — drafting and exploring ideas in Vibe, running structured experiments in the AI Studio Playground, and, in a dedicated project workspace, using the API for larger or repeatable workflows. Document AI and audio transcription are part of the same offering.

Mistral stays a **research-supporting tool**. It is there to help you work, not to replace your judgement. Used well, it can speed up reading, writing, coding, and analysis on projects that until now had to stay off these platforms because of their data classification.

If you already use Mistral, you can keep going — and if you have been waiting for Level 3 approval, now is a good time to apply.
