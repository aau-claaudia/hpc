# Getting started with UCloud — webinar on 1 October

Whether you are new to UCloud or already using it, this is a practical hour on how the platform works after the move to the new data centre.

**1 October 2026, 12:30–13:30**, online via Zoom.

The session is for researchers across all disciplines. The level is beginner to intermediate, and no prior experience with UCloud is required.

## What you will learn

- How to navigate the new interface and reach your projects and resources.
- How to manage files and drives: create and organise project drives, and upload and share data.
- How to find applications in the catalogue and run them on UCloud.
- Which compute resources are available, and how to choose what fits your research.

The webinar is run by the Interactive HPC Consortium (Aalborg University, Aarhus University, and the University of Southern Denmark). [CLAAUDIA](https://www.researcher.aau.dk/contact/claaudia) is Aalborg University’s local support team for UCloud.
