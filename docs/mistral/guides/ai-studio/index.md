# AI Studio

AI Studio is Mistral's developer platform, available at [console.mistral.ai](https://console.mistral.ai){target="_blank"}. It is designed for structured experimentation, API integration, and building repeatable AI-powered workflows. It includes a Playground for testing models interactively, API key management, usage monitoring, and tools for building and deploying agents.

At AAU, basic access to AI Studio (Playground, Document AI, Audio transcription) is available through the same SSO login as Vibe and is for **Level 1 data only**. A dedicated workspace is required for API keys and for Level 2 or 3 data — see [How to Access Mistral](/mistral/how-to-access/) for details.


For a full overview of AI Studio features, see Mistral's official [AI Studio — Documentation](https://docs.mistral.ai/deployment/ai-studio){target="_blank"} 

## Workspace quota

Each workspace has a monthly usage quota of **€50**. This covers API usage (tokens consumed across all models) within that workspace for the month. Note that model prices vary significantly — larger and more capable models consume the quota faster than smaller ones. See [Mistral's pricing page](https://docs.mistral.ai/models){target="_blank"} for a full overview.

## Data Classification

!!! warning "Sensitive data only in a dedicated workspace"
    Data classified as **Level 2 or 3** may only be processed in a **dedicated workspace** requested through the Serviceportal. Do not enter such data in the default workspace. API keys are issued only after Grants and Contracts has assessed the project and a WorkZone case number has been provided. Build **human-in-the-loop** into API workflows: model output must not automatically lead to actions, classifications, or research conclusions. See [Responsible use of Mistral](/mistral/guides/responsible-use/) and the [Terms and Conditions](/mistral/terms-and-conditions/). <!-- 10 --><!-- 19 -->
