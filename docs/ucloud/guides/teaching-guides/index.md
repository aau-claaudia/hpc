# Before you start

UCloud offers many possibilities for data analysis, AI, machine learning, simulation, and other computational tasks. This also makes it a valuable platform for teaching and educational activities.

Before creating a teaching project, please familiarize yourself with the guidelines for resource allocation and project applications.

## Apply for a Teaching Project
To apply for a teaching project, follow the step-by-step guide:
👉 [Expanded Application Guide](https://hpc.aau.dk/ucloud/expanded-application-guide/)

When submitting your application, select **"AAU Education"** as the grant provider.

## Resource Allocation Guidelines
As a general rule, teaching projects can apply for up to the following resource limits for each 3 month:

| Resource Type | Maximum Allocation |
|---------------|-------------------|
| CPU Hours | 15,000 |
| GPU Hours | 300 |
| Storage | 1000 GB |

> **Note:** If you apply with a timeframe of 1 month, the maximum allocation are limited to 5,000 CPU Hours, 100 GPU Hours and 1000 GB storage.

> **Note:** Resource requests beyond these limits require additional justification and will be evaluated on a case-by-case basis.


## Need Help?
If you have questions about UCloud or encounter challenges while setting up your teaching environment, you are always welcome to contact **Claudia** through the [Service Portal](https://serviceportal.aau.dk/serviceportal?id=sc_cat_item&sys_id=a05e2fb4c3434610f0f3041ad001310e).
